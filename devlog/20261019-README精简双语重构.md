## 用户原始需求

1. 一键安装：官方插件中心 / npm / Git（三选一）

## 背景

- Paseo 0.11.0 起 `paseo plugin add owner/slug` 解析为**插件注册表 id**，直连 GitHub 必须写 `github:owner/repo`，本地目录用 `.` / `./path`。
- 本插件注册表 id 为 `mousebomb/solarized`（≠ GitHub 仓库名 `paseo-solarized`），npm 包为 `@mousebomb/paseo-solarized`。
- 原 README 的「方式2 Git 安装」写的是 `mousebomb/paseo-solarized`，在 0.11 上会被当成不存在的注册表 id 而失败；`paseo plugin status` 子命令也不存在。
