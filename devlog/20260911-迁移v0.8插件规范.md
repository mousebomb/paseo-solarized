# 2026-09-11 Solarized Light 插件迁移 Paseo v0.8 规范

## 用户原始需求

Paseo v0.8.0 发布（2026-09-10），插件机制调整。用户先要求评估冲击，确认升级 host 后插件加载失败，随后要求把插件代码改造为 0.8 规范。

## 问题定位

升级到 0.8.0 后 `paseo plugin ls` 报错：

```
Plugin "solarized-light" requires Paseo <0.8.0. Your daemon is 0.8.0.
This plugin has no requirements.paseo and targets Paseo before 0.8.
```

根因：插件仍是 0.5 混合根入口 `index.ts`（`plugin.addTheme`）+ 手写 `paseo-plugin.d.ts` 模拟旧 API，`paseo-plugin.json` 无 `requirements`。0.8 拆分了 client/server 运行时入口（PR #4347）并强制要求 manifest 声明 Paseo 版本下限（PR #4430）。

核对官方迁移文档 `https://paseo.sh/docs/plugins/v0.8/migration` 与 v0.8 reference 后确认：`client.addTheme` 颜色契约不变（仍 8 字段，`accent` 可选），纯数据主题无需 server 入口。

## 解决方案

4 处改动：

1. **入口重构**：`git mv index.ts index.client.ts`；`plugin.addTheme(theme)` → `client.addTheme(theme)`，context 类型换真实 SDK 的 `PluginClientContext`（`@getpaseo/plugin/client`）。
2. **manifest 声明版本**：`paseo-plugin.json` 加 `"requirements": {"paseo": ">=0.8.0"}`（缺省即视为 `<0.8.0`，会被 0.8 host 拒绝）。
3. **依赖替换**：删手写 `paseo-plugin.d.ts`；`package.json` 新增 `@getpaseo/plugin@^0.8.0`，`@getpaseo/client` 从 `^0.4.0` 升 `^0.8.0`，均已在 npm 发布。
4. **文档沉淀**：AGENTS.md 适配版本 0.5.1 → 0.8.0，新增「v0.8 插件结构规范」小节，检查项含入口命名、`requirements.paseo`、真实 SDK 类型、颜色契约不变。

## 验证

- `npm run typecheck` 通过（真实 SDK 类型解析，`addTheme(contribution): PluginCleanup` 契约匹配）。
- `paseo plugin reload solarized-light` 热重载成功；`paseo plugin ls` 预期为 `running`。

## 备注

- 声明 `>=0.8.0` 后插件不再兼容 0.8 以下 host，但官方明确不留兼容入口，属预期取舍。
- 0.8 起 `paseo plugin ls` 本地即可显示 runtime state 与 load errors，无需 remote。
