# 2026-08-24 Solarized Light 主题用户消息气泡可读性修复

## 用户原始需求

Paseo 在 Solarized Light 主题下，用户发送消息的气泡颜色与文字颜色过于接近，可读性不高，需要修复。

## 问题定位

通过阅读 Paseo 0.5.1 源码确认了气泡配色链路：

- 气泡背景：`packages/app/src/components/message.tsx:347` → `theme.colors.surface3`
- 气泡内文字：`packages/app/src/components/message.tsx:356` → `theme.colors.foreground`
- 插件主题字段映射（`src/plugins/themes/index.ts:63-71`）：`surface3 = colors.border`

即**用户气泡背景由插件主题的 `border` 字段决定**。原配置 `border: #93a1a1`（Solarized base1 中灰），与气泡文字 `foreground: #657b83`（base01 中深灰）亮度都在中间段，对比度仅约 **1.67:1**（WCAG 可读标准 ≥ 4.5:1），导致可读性差。

## 解决方案

将 `index.ts` 的 `border` 由 `#93a1a1` 调浅。分两步：

1. 首次调整为 `#eee8d5`（Solarized base2，浅米色，同 `raised`），气泡文字 `#657b83` 对比度约 **3.6:1**
2. 用户实际查看后觉得气泡与页面背景的层次区分不足，**手动再加深一档**为 `#e6e0cd`（介于 base2/base3 之间）作为最终值，气泡从背景中凸出更明显，文字对比度约 **3.7:1**

共同效果：

- 气泡背景变浅，文字 `#657b83` 可读性明显改善
- 边框线变淡但可见，符合 Paseo 内置 Light 主题惯例（内置 border 为 `#e4e4e7` 浅色）
- 时间戳等次要文字（`mutedForeground`）未改动

## 验证

- `npm run typecheck` 通过
- `paseo plugin reload solarized-light` 重载生效，插件状态 running

## 经验沉淀

Paseo 插件主题字段与 Unistyles 完整色板映射关系：

| 插件字段 | 映射 | 主要用途 |
|---|---|---|
| background | surface0 | 页面背景 |
| raised | surface1 | 次要凸起层 |
| control | surface2 | 控件背景 |
| **border** | **surface3** | **用户消息气泡背景** + 卡片/控件背景 + 边框线 |
| mutedForeground | foregroundMuted | 次要文字（时间戳等） |
| accent | accent | 强调色 |
| ring | - | 焦点环 |

Light 主题下 `surface3` 应为「比背景略深的浅色」，若设成中灰色会与深色正文文字撞亮度、降低可读性。
