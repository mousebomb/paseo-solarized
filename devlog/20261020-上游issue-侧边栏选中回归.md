# 2026-10-20 上游 issue：0.12.0 浅色插件主题侧边栏选中回归

## 用户原始需求

Paseo 升级 0.12.0 后，Solarized Light 在左侧 Workspaces 中选中项目时，高亮行背景和文字都是深色、难以辨识。需要确认是上游改动还是主题问题，并决定是否跟随适配。

## 调查结论

- 回归来自 0.12.0 的 `01f9bc8`（PR #6431，作者 boudra），PR 目标写明 "use darker light-theme hover and selected fills"，是刻意调深。
- 具体改动：`packages/app/src/styles/theme.ts` 的 `buildLightSemanticColors`，`surfaceSidebarSelected` 从 `surface3` 改为 `surface4`，`surfaceSidebarHover` 从 `surface1` 改为 `surface3`。
- 内置主题的 `surface4` 是独立浅灰（Light `#d4d4d8`），选中行 11.7:1，所以上游 QA 没暴露问题。
- 插件主题没有 `surface4` 字段，宿主 `packages/app/src/plugins/themes/index.ts` 将其映射为 `ring`；文档把 `ring` 定义为 focus rings / scrollbars / terminal bright black，浅色主题下本就是深色前景。
- 同一 token 还驱动 `composer/input/input.tsx` 的 placeholder 颜色和 `usage/meter.tsx` 的 `fillQuiet`，因此这两处也被污染。
- 深色端选中行用 `surface2`，不受影响；仅浅色端中招。

## 本地绕路尝试

- `ring` 改深（用户实测 `#002b36`）：选中行可读，但 placeholder 与进度条变深，浅色界面里混入深色元素，观感差，放弃。
- `ring` 改浅：选中行可读，但 sidebar 时间戳与终端 bright black 变成近白不可见。
- `ring` 改中间调：选中 1.67:1、时间戳 2.18:1，两头不达标。
- 结论：8 色契约内不存在可接受的解，必须上游修。

## 已执行

- 用 web 客户端（`app.paseo.sh` 连接本地 0.12.0 daemon）复现：临时安装 `solarized-repro`（内容等同 0.1.1，`ring: #586e75`），选中行计算样式为背景 `rgb(88,110,117)`、标题 `rgb(101,123,131)`，对比度 1.21:1。
- 截图裁剪侧边栏，经 gist 托管：<https://gist.githubusercontent.com/mousebomb/6b65a1abf11e662d09149a076db9a981/raw/sidebar.png>
