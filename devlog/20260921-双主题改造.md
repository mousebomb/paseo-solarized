# 2026-09-21 克隆新仓库并改造为 Solarized 明暗双主题

## 用户原始需求

原仓库 `mousebomb/paseo-solarized-light` 只做了 Solarized Light 单主题。用户决定保留旧仓库，另开新仓库做「明暗双色」版本。已从旧仓库克隆代码到新路径 `/Users/rhett/MyWork/2026/paseo-solarized`（新仓库 `mousebomb/paseo-solarized`），要求在这里追加 Solarized Dark 主题，实现同一个插件贡献明暗两套主题。

## 问题定位

- 单主题入口 `index.client.ts` 只调了一次 `client.addTheme`，贡献 id 为 `solarized-light`。
- 新仓库若沿用旧插件 id `solarized-light`，会与旧仓库插件冲突（Paseo 按 daemon 配置键索引已安装插件）。旧仓库保留 ⇒ 新插件 id 必须错开。
- 双主题技术前提已核实：上游 `packages/app/src/plugins/themes/index.ts` 遍历的是 `plugin.themes` 数组，主题贡献 id 自动加 `${plugin.id}/theme/` 前缀；官方 e2e `plugin-theme.spec.ts` 就是「一个插件连续 addTheme 两次（dark + light）」的现成先例。

## 解决方案

1. **入口改为双主题**：`index.client.ts` 连续两次 `client.addTheme`，贡献 id 用 `light` / `dark`（前缀后为 `solarized/theme/light`、`solarized/theme/dark`）。
2. **插件 id 错开**：`paseo-plugin.json` 的 `id` 由 `solarized-light` 改为 `solarized`；`package.json` name 改为 `paseo-solarized`。
3. **深色端配色**（遵守 8 字段契约与对比度约束）：
   - `background` base03 `#002b36`、`foreground` base0 `#839496`（正文 4.75:1；base00 仅 3.4:1 不可用）
   - `raised` / `control` base02 `#073642`
   - `border` base02（用户气泡背景，气泡文字 4.11:1）
   - `accent` cyan `#2aa198`（与背景 4.75:1；orange 仅 3.28:1 不可用）
   - `mutedForeground` base01 `#586e75`、`ring` base1 `#93a1a1`
4. **文档同步**：README.md / README.en.md 改为双主题说明 + 色板对照表 + 新仓库名/新 id 命令；AGENTS.md 记录双主题注册机制、id 由 daemon 配置键决定、深色端对比度实测值；本 devlog。

## 验证

- `npm run typecheck` 通过（`addTheme` 两次调用均匹配真实 SDK 契约）。
- `paseo plugin reload solarized-light`（当前配置键仍是旧键）日志 `Loading plugin` → `Plugin ready`，无加载错误，深色主题已随新代码生效。

## 备注

- 旧配置键 `solarized-light` 仍指向本仓库，manifest id 已改为 `solarized`；daemon 用配置键当插件 id（`loadDirectoryPlugin` 里 `id: pluginId`），`reload` 不会换前缀。要让插件以 `solarized` 注册，需 `paseo plugin remove solarized-light` 后 `paseo plugin install <本目录>`。
